# Mock exams

An original 50-question mock paper covering both tracks — Faster Payments analyst topics and the broader CPCM curriculum. Questions are new and written for this site; treat it as a realistic-format practice sitting, not a leaked past paper.

**Instructions:** Allow 60–75 minutes. Attempt every question before checking the answer key at the bottom. Each question has one correct answer.

## Section A — FPS fundamentals & lifecycle (Q1–15)

**1.** What best describes the Faster Payments Service?

- A) A batch clearing system that settles every three days
- B) A UK real-time payment scheme available 24/7/365
- C) A card scheme for merchant payments
- D) A cross-border SWIFT messaging network

**2.** Who operates the central FPS scheme infrastructure and rulebook?

- A) The Bank of England
- B) Pay.UK
- C) The Payment Systems Regulator
- D) Each individual bank independently

**3.** An indirect participant accesses FPS through:

- A) A direct connection to Pay.UK's infrastructure
- B) A sponsor bank
- C) SWIFT messaging
- D) The Bank of England's RTGS system

**4.** Which of these is NOT typically a validation check performed before FPS submission?

- A) Sort code format check
- B) Modulus checking of the account number
- C) Credit score assessment
- D) Mandatory field completeness

**5.** Confirmation of Payee primarily protects against:

- A) Currency conversion errors
- B) Misdirected payments and authorised push payment fraud
- C) Card skimming
- D) Cheque forgery

**6.** Which CoP outcome tells the customer the name is close but not exact?

- A) Match
- B) Close Match
- C) No Match
- D) Unable to Check

**7.** A payment being "accepted by FPS" means:

- A) The beneficiary has definitely been credited
- B) The message was routed successfully; the receiving bank still has processing to do
- C) Settlement has finalised
- D) The payment cannot be reversed under any circumstances

**8.** The difference between a rejection and a return is:

- A) There is no difference
- B) A rejection happens before completion; a return happens after a completed payment is sent back
- C) A return only applies to CHAPS
- D) A rejection can only be issued by Pay.UK

**9.** Which of these is a plausible reason a technically valid payment is still delayed?

- A) The sort code has six digits
- B) It triggered a fraud or risk-scoring rule
- C) It was submitted on a weekday
- D) The amount was under £10

**10.** An exception queue exists to:

- A) Automatically cancel every payment that enters it
- B) Hold payments that can't proceed through normal automated processing for investigation
- C) Replace the need for validation checks
- D) Store completed payments for archival only

**11.** What is the primary purpose of a Payment ID versus a Correlation ID?

- A) They are always the same value
- B) The Payment ID is the business reference; the Correlation ID ties together messages for the same payment across systems
- C) The Correlation ID is only used for CHAPS
- D) The Payment ID is generated by the customer

**12.** Which best describes the relationship between FPS processing and settlement?

- A) They are the same process under different names
- B) Processing moves the payment instruction; settlement clears the financial obligation between institutions
- C) Settlement always happens before processing
- D) Settlement is irrelevant to Faster Payments

**13.** A sponsor bank's role for an indirect participant includes:

- A) Setting national interest rates
- B) Providing connectivity and settlement arrangements to the scheme
- C) Issuing debit cards on the participant's behalf
- D) Acting as the customer's employer

**14.** Why is FPS available outside normal banking hours, unlike Bacs?

- A) It was designed from the outset for real-time, always-on processing rather than batch cycles
- B) Banks are legally required to staff branches 24/7
- C) It only processes low-value payments so risk is ignored
- D) Bacs is being phased out entirely

**15.** A customer reports a payment as "missing." What should you check first?

- A) The customer's home address
- B) The payment's status history and where processing last confirmed a step
- C) The bank's marketing calendar
- D) The exchange rate at time of payment

## Section B — Investigation, reconciliation & systems (Q16–30)

**16.** A reconciliation break where a payment exists on one system but not the other is best classified as:

- A) An amount mismatch
- B) A missing-record break
- C) A duplicate
- D) A status mismatch

**17.** What commonly causes a duplicate payment to appear in a system?

- A) Correct first-time processing with no retries
- B) A retry after a timeout where the original request had actually succeeded
- C) The customer manually approving CoP
- D) A scheduled maintenance window

**18.** In a payment hub architecture, which of these typically sits closest to the customer-facing channel?

- A) The FPS gateway
- B) Pay.UK's central infrastructure
- C) The API layer receiving the initial payment request
- D) The receiving bank's core ledger

**19.** Which SQL clause would you use to narrow a search to only failed payments in a given date range?

- A) ORDER BY
- B) WHERE
- C) GROUP BY without any condition
- D) DISTINCT alone

**20.** Middleware in a payments architecture is best described as:

- A) The customer-facing mobile app
- B) The layer that moves and queues messages between systems
- C) A type of fraud rule
- D) A regulator's reporting tool

**21.** When investigating a spike in failed payments, an effective first step is to:

- A) Immediately restart all production systems
- B) Group failures by reason code to check for a concentrated root cause
- C) Ignore it if it resolves within an hour
- D) Contact every customer individually before any analysis

**22.** What does a database audit trail typically provide during an investigation?

- A) The customer's marketing preferences
- B) A record of status changes and related events for a payment over time
- C) The bank's annual financial statements
- D) A list of unrelated transactions

**23.** Which of the following is the strongest signal that a delay is scheme-side rather than internal?

- A) The payment status shows an internal validation failure code
- B) The payment cleared internal validation and fraud checks but has no response from the FPS gateway
- C) The customer used the wrong app
- D) The account was opened yesterday

**24.** A "happy path" test scenario is best described as:

- A) A test designed to fail intentionally
- B) A valid, expected scenario used to confirm the system works end-to-end under normal conditions
- C) A test that only checks the user interface colours
- D) A test that skips fraud checks entirely

**25.** Why is negative testing particularly important for payment systems?

- A) It has no real value beyond compliance box-ticking
- B) Poorly handled failures can cause financial loss, duplicate payments, or unclear customer outcomes
- C) It replaces the need for happy-path testing
- D) It is only relevant to card payments

**26.** What would a sudden, unexplained drop in payment volume most likely indicate?

- A) A quiet bank holiday with no other cause
- B) A possible upstream issue preventing payments from reaching the system at all
- C) Definitely nothing — volume naturally fluctuates and needs no investigation
- D) A successful marketing campaign

**27.** Which metric combination is most useful for 24/7 production monitoring of a payment platform?

- A) Only the number of customer complaints received by post
- B) Volume, success/failure rate, queue depth, and dependency health
- C) Office attendance figures
- D) Only the total number of registered customers

**28.** What is the primary goal of triaging a reconciliation break by type before investigating?

- A) To avoid investigating altogether
- B) To route it to the right process instead of investigating every break from scratch
- C) To automatically write off the discrepancy
- D) To reassign it to the customer

**29.** Which identifier would most help you trace one payment across the payment hub, gateway, and receiving-bank logs?

- A) The customer's date of birth
- B) A correlation or end-to-end reference shared across the systems
- C) The bank's head office postcode
- D) The current interest rate

**30.** What distinguishes production support monitoring from one-off investigation work?

- A) There is no difference
- B) Monitoring is continuous and proactive; investigation is typically reactive to a specific reported issue
- C) Monitoring only happens once a year
- D) Investigation never uses system logs

## Section C — CPCM curriculum: clearing, cards & cross-border (Q31–42)

**31.** Clearing is best defined as:

- A) The final, irreversible movement of funds
- B) The exchange and calculation of payment obligations between banks before settlement
- C) A synonym for authorisation
- D) A card scheme function only

**32.** RTGS stands for:

- A) Retail Transaction Government Service
- B) Real-Time Gross Settlement
- C) Regional Transfer Guarantee Scheme
- D) Rapid Treasury General Settlement

**33.** CHAPS payments, once settled, are generally considered:

- A) Reversible for 30 days on request
- B) Final and irrevocable
- C) Automatically refunded if disputed
- D) Held for a week before finalising

**34.** A nostro account is described from the perspective of:

- A) The correspondent bank holding the account
- B) The bank that owns the account held with a correspondent abroad
- C) The regulator
- D) The card scheme

**35.** SEPA Instant Credit Transfer is designed to settle:

- A) Only during business hours
- B) Within seconds, 24/7, within the eurozone
- C) Only for business accounts
- D) Once every three days

**36.** In the four-party card model, who typically pays the interchange fee?

- A) The cardholder directly, at point of sale
- B) The acquirer, to the issuer
- C) The scheme, to the merchant
- D) The regulator

**37.** Tokenisation in card payments is used to:

- A) Increase the amount of sensitive data stored by merchants
- B) Replace sensitive card data with a non-sensitive substitute value
- C) Remove the need for any authorisation step
- D) Slow down transaction processing intentionally

**38.** Merchant acquiring refers to:

- A) Issuing cards directly to consumers
- B) Enabling a merchant to accept and receive card payment funds
- C) Setting global card scheme rules
- D) Operating a country's RTGS system

**39.** What is the key liquidity trade-off of gross settlement compared with deferred net settlement?

- A) Gross settlement needs less liquidity but carries more risk
- B) Gross settlement typically needs more liquidity but reduces settlement risk
- C) There is no liquidity difference between the two
- D) Deferred net settlement is always risk-free

**40.** An MT-style SWIFT message is best described as:

- A) A card authorisation request
- B) A structured message format used for interbank payment instructions and communication
- C) A domestic-only UK message standard
- D) A cheque image format

## Section D — Risk, regulation & current topics (Q43–50)

**41.** Authorised push payment (APP) fraud is distinctive because:

- A) The payment fails every technical validation check
- B) The customer is deceived into authorising a genuine payment to a fraudster
- C) It only occurs on CHAPS
- D) It requires no customer involvement at all

**42.** Under the UK's mandatory APP fraud reimbursement regime, reimbursement cost is generally:

- A) Borne entirely by the customer
- B) Split between sending and receiving payment firms in most cases
- C) Always waived if the amount is small
- D) Paid directly by the Bank of England

**43.** ISO 20022 messaging is significant mainly because it:

- A) Removes the need for any payment validation
- B) Provides richer, more structured data that helps with fraud detection and reconciliation
- C) Applies only to cheque processing
- D) Replaces the need for sort codes

**44.** Know Your Customer (KYC) checks are primarily designed to:

- A) Improve marketing targeting
- B) Verify customer identity and assess risk before or during onboarding
- C) Set the customer's interest rate
- D) Replace the need for fraud monitoring entirely

**45.** Sanctions screening in payments operations exists to:

- A) Slow down all payments equally regardless of risk
- B) Prevent funds from reaching parties or jurisdictions subject to legal restrictions
- C) Calculate currency conversion rates
- D) Determine card interchange fees

**46.** Open Banking, in a UK payments context, primarily enables:

- A) Regulated third parties to access account data or initiate payments with customer consent
- B) Banks to ignore data protection law
- C) Only card payments, not bank transfers
- D) The end of all customer authentication

**47.** A Variable Recurring Payment (VRP) differs from a standard standing order mainly by:

- A) Being a fixed, unchangeable amount forever
- B) Allowing payments within a customer-agreed variable range and conditions, initiated via Open Banking
- C) Only being available for salary payments
- D) Requiring a paper mandate each time

**48.** Why do payment firms need a defined incident communication process, not just a technical fix?

- A) Technical fixes never require communication
- B) Stakeholders and customers need clear, accurate, non-technical updates during and after an incident
- C) Communication is only required for outages lasting over a month
- D) Regulators forbid firms from communicating during incidents

**49.** When comparing FPS with equivalent real-time payment systems internationally, a useful comparison point is:

- A) Whether the system has a website
- B) Availability, participant model, and message standards used
- C) Only the country's currency symbol
- D) The number of bank holidays in that country

**50.** Which best describes operational resilience expectations for a payments firm?

- A) Systems only need to recover eventually, with no defined targets
- B) Firms must be able to identify important business services and remain within agreed impact tolerances during disruption
- C) Resilience only applies to marketing systems
- D) There is no regulatory expectation around resilience
