## How to use these

Each sheet is self-contained and printable — open it, `Ctrl/Cmd+P`, done. They're deliberately terse: short definitions and runnable snippets rather than full explanations. If a term doesn't make sense on its own, search for it using the [Knowledge Assistant](../assistant/index.md) or browse the related lesson track.

Got a cheat sheet you'd like added? Treat it the same way as any other [deep dive](../deep-dives/index.md) — it's easy to add another page here.
